## 出力の凍結を外すとき

改修が落ち着いたら外します。そのとき消すのは**この4つ**です。忘れると死んだ検査が残ります。

| 消すもの | 何か |
|---|---|
| `.ichiki/snapshot.json` | 期待値（96ファイルのハッシュ） |
| `.claude/ichiki/src/snapshot.js` | 本体 |
| `.claude/ichiki/bin/ichiki.js` の `snapshot` 行 | コマンド登録 |
| `.claude/ichiki/src/gate.js` の `--snapshot` と「出力の凍結」ステップ | gate からの呼び出し |

`package.json` の `test:update` は `test/run.js`（scan の回帰）で**別物です。残します。**
